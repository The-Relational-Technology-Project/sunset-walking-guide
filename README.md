# Sunset Walking Guide

A location-aware mobile field guide for walking the Outer Sunset neighborhood of San Francisco — nearby places sorted by distance, curated tours, and swipeable place cards.

## What is this?

Sunset Walking Guide uses your phone's GPS to show what's nearby as you walk through the Outer Sunset. Browse places sorted by distance, swipe through place cards, follow curated walking tours, or view everything on a map. Built as a progressive web app optimized for mobile use in the field.

## Features

- **Nearby places** — GPS-sorted list of interesting spots around you
- **Swipeable cards** — Flip through places with photos and descriptions
- **Map view** — See all places and your location on an interactive map
- **Curated tours** — Follow themed walking routes through the neighborhood
- **All stops list** — Browse every place in the guide
- **Place details** — Rich detail sheets with photos, history, and directions
- **Mobile-first** — Progressive web app with bottom-tab navigation

## Tech stack
